# Legacy materials

This directory retains historical project files that are not used by the
current thesis, errata, or MATLAB figure-generation workflow.

- `documents/` contains the standalone abstract, approval page, defense deck,
  and NASA STI review form.
- `images/diagrams/` contains raster block diagrams superseded by the active
  TikZ sources in `images/diagrams/tikz/`.
- `images/timing/` contains raster timing diagrams superseded by the active
  TikZ timing diagrams.
- `sections/` contains retired appendix drafts superseded by the current
  front-matter nomenclature.

The files remain version controlled for historical reference. Active plots,
characterization data, source code, supporting materials, and released PDFs
remain outside this directory.
